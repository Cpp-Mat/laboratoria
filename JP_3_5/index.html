    01 / TWOJE ZADANIE
    Dwie operacje.
    Jeden ważny warunek.
    1. Wczytaj znak operacji do zmiennej typu char.
    2. Dla + lub - wczytaj dwie liczby typu double, wypisz nazwę operacji i wynik.
    3. Dla innego znaku wypisz Niedozwolona operacja: oraz ten znak. Zakończ program przed wczytaniem liczb.
    Wskazówka: znak jest nieprawidłowy, gdy jednocześnie nie jest plusem i nie jest minusem.
    
        
    02 / OCZEKIWANE ZACHOWANIE
    Sprawdź na przykładzie
    Dane wejściowe
    Oczekiwany komunikat
    To przykłady wzorcowe, niezależne od ułożenia linii. Liczby wpisuj z kropką dziesiętną.
    
        
    Jak pracować z układanką?
    1. Przesuwaj linie za uchwyt ⠿ lub przyciskami ↑ ↓. Na telefonie używaj przycisków.
    2. Klawiatura: przejdź klawiszem Tab do przycisku linii, potem użyj Alt + ↑ / ↓. Przyciski działają też przez Enter lub spację.
    3. Wybierz „Sprawdź kolejność”. Podpowiedź dotyczy pierwszego naruszenia zasad; zielone linie oznaczają poprawny początek.
    4. „Pomieszaj od nowa” losuje kolejność i zeruje licznik sprawdzeń. „Pokaż rozwiązanie” wymaga potwierdzenia.
    Zasada oceny: deklaracje mogą być przed lub po komunikatach cout, ale muszą poprzedzać odpowiednie cin i obejmować zakresem wszystkie użycia zmiennych. Można je umieścić bezpośrednio w main lub przed funkcją jako zmienne globalne. Deklaracja liczb może też poprzedzać walidację znaku. Pozostałe instrukcje porównujemy z wzorcem dydaktycznym. Identyczne klamry i instrukcje return 0; są zamienne.
    Sprawdzamy kolejność, nie kompilację. Strona nie wykonuje C++, nie wysyła kodu i nie zapisuje ocen. Odświeżenie zaczyna nowe ćwiczenie.
    O liczbach: program używa domyślnego formatowania cout (6 cyfr znaczących), bez wymuszania dwóch miejsc po przecinku. Nie porównuje wyników typu double operatorem ==. Zakładamy poprawne dane liczbowe po dozwolonym znaku operacji.
